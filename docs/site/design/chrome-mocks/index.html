1. Marketing Header (Decisions 1, 2, 3, 4, 5)

2. Documentation Header (Decisions 1, 2, 3, 7)

Solid 56px hairline bar. Area tabs (Start, Guides, Algorithms, Reference, Design, Project) at ≥ 1280px; "Section" disclosure dropdown at 1024–1279px. Full 260px search trigger with Ctrl+K shortcut and no CTA.

3. Mobile Bar (52px) & Modal Sheet Dialog (Decisions 1, 5)

Slim 52px mobile bar with logo, search icon, and 44px Menu button. Sliding native <dialog> sheet drawer with focus trap, full-width search, 48px link rows, Algorithms accordion, and preferences.

4. Footers: Full Marketing & Slim Docs (Decision 6)

Full 12-column footer with optional 12px ruler edge, brand block, 3 link columns, and bottom legal/preferences strip. Slim 72px docs footer attached to docs container.
