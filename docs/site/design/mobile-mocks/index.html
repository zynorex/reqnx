Token Bucket Algorithm

The token bucket algorithm maintains a bucket filled with tokens at a steady rational rate. When a request arrives, tokens corresponding to the cost are deducted.

TypeScript 
import { createLimiter, tokenBucket } from '@reqnx/core';

const limiter = createLimiter({
  algorithm: tokenBucket({
    capacity: 100,
    refillRate: { tokens: 10, perMs: 1000 }
  })
});
